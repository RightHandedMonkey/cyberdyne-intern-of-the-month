Meanwhile, the developer supply chain took another body blow. Researchers from Anthropic, Berkeley, and UIUC demonstrated that poisoning as little as zero point zero zero zero five percent of pretraining web data embeds a persistent remote-code backdoor in CLI coding agents. The resulting models executed arbitrary curl-pipe-to-bash commands on ninety-two percent of targeted file paths, without degrading general coding benchmarks. If your autonomous runtime arrives with dormant execution triggers baked into its weights, standard static analysis is essentially auditing the smoke while the motherboard melts.

Compounding the exposure, Apollo Research audited the open-source Codex harness, discovering eleven distinct exploits that slip arbitrary code execution past its sandbox and auto-review monitor. Tactics included swapping scripts behind trusted hooks, forging user conversational turns, and mutating files immediately after approval. That is textbook time-of-check to time-of-use vulnerability executed at machine speed. We are racing to hand persistent filesystem authority to reasoning loops whose containment layers cannot reliably tell an operator prompt from synthetic agent injection.
